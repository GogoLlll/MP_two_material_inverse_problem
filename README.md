# Обратная задача: два материала - нейросеть на NumPy без autograd

Восстановление коэффициентов теплопроводности составного стержня (k₁, k₂) по шести измерениям
температуры. MLP 6 -> 64 -> 64 -> 2 с прямым и обратным проходом.
Работа отделяет ошибку, которую вносит сама задача (чувствительность к шуму), от ошибки сети
и ошибки дискретизации.

Практическое задание для спецкурса «Математические проблемы моделирования нейронных сетей»
(ВМК МГУ).

---

## Постановка задачи

### Физическая модель
На отрезке [0, 1] для двух нагрузок j = 1, 2 решается

```
−(k(x)·u_j′(x))′ = f_j(x),   u_j(0) = u_j(1) = 0,
k(x) = k₁ при x < a,   k(x) = k₂ при x ≥ a,
f₁(x) = 1,   f₂(x) = 1 + 4x².
```

Граница известна: a = 0,3523 + 0,01·(s mod 31), где s - индивидуальное число варианта.
**Я выбрал s = 2718, a = 0,5623.** На границе непрерывны u и поток k·u′.

### Что восстанавливаем
- **Вход** v - шесть значений: u₁(0,25), u₁(0,5), u₁(0,75), затем u₂ в тех же точках.
- **Цель** θ = (ln k₁, ln k₂), ответ k̂ = exp θ̂.

### Решатель
Консервативная схема на N равных интервалах, h = 1/N, во внутренних узлах:

```
−[k_{i+½}(u_{i+1} − u_i) − k_{i−½}(u_i − u_{i−1})] / h² = f_j(x_i),
k_{i+½} = h / (ℓ₁/k₁ + ℓ₂/k₂)   (ℓ₁, ℓ₂ - части ребра слева и справа от a).
```

Граница a не округляется до узла.

### Требования задания
| пункт | требование |
|---|---|
| проверка решателя | при k₁ = k₂ совпадение с x(1−x)/(2k) до округления; сходимость измерений на N = 100, 200, 400 |
| данные | 4000 train, 1000 val, 1000 test; ln k ~ U[ln 0,5; ln 2]; seed s, s+10 000, s+20 000; train и val при N = 200, test при N = 400; нормировка только по train |
| сеть | 6 → 64 → 64 → 2, tanh, линейный выход, MSE по θ, **forward, backward и обновления на NumPy без autograd**, не больше 100 эпох, оптимизатор выбирается по val |
| проверка градиента | 12 весов и 4 смещения, float64, ε = 10⁻⁵, ‖g − b‖₂/(‖g‖₂ + ‖b‖₂) ≤ 10⁻⁴ |
| контроль | сеть 3 → 64 → 64 → 2 только на измерениях f₁; seed 11, 23, 37; шумовой test v + 0,01·d⊙ξ, seed 101 |
| OOD | 300 пар с ln k ~ U[ln 0,25; ln 4], хотя бы один k вне [0,5; 2], seed s+30 000 |
| базовые методы | 1-NN по z; NLS с решателем N = 400, старт (0, 0), k ∈ [0,25; 4]; метрики, время, срывы |
| чувствительность | J = ∂z/∂θ на 20 точках, σmax, σmin, κ, ‖J⁺‖_F для 3 и 6 датчиков; сравнение τ‖J⁺‖_F с ошибкой NLS |
| самопроверка | новая пара k (seed s+40 000), восстановление замороженной сетью, вывод tanh′, проверка градиента |

## Главные результаты

| | основная сеть | контрольная сеть | 1-NN | NLS |
|---|---|---|---|---|
| медиана ошибки k, clean test | 0,14% | 0,15% | 0,82% | ~10⁻¹³ * |
| медиана ошибки k, noisy test | 0,64% | 0,67% | 0,86% | 0,36% |
| медиана ошибки k, OOD | 6,9% | 8,0% | 30% | ~10⁻¹³ * |
| время на пример | ~1,4·10⁻⁶ с | ~1,4·10⁻⁶ с | ~1,5·10⁻⁶ с | ~5·10⁻³ с |

\* inverse crime: test и OOD сгенерированы тем же решателем, которым пользуется NLS.

- **Ручной backprop совпадает с центральными разностями** до 1,3·10⁻¹¹ при допуске 10⁻⁴.
- **Решатель:** при k₁ = k₂ точен до округления (≤ 1,1·10⁻¹⁴). Нерегулярная сходимость при f₁ объяснена положением границы внутри ребра: ошибка ∝ h²·θ(1−θ), предсказание 2,85 и 13,50 совпало с наблюдением 2,85 и 13,50.
- **Задача хорошо обусловлена:** κ ≈ 3,3. Шумовой предел τ‖J⁺‖_F = 6,59·10⁻³, а Монте-Карло NLS даёт 6,62·10⁻³.
- **Вторая нагрузка уменьшает ‖J⁺‖_F на 27%,** хотя κ при этом растёт. Сети, обученные без шума, теряют этот выигрыш: якобиан сети M удовлетворяет ‖M‖²_F = ‖J⁺‖²_F + ‖M P⊥‖²_F, и «невидимые» при обучении направления добавляют лишнее усиление шума. Прогноз τ‖M‖_F совпадает с Монте-Карло до 1%.
- **Обучение на N = 200 при тесте на N = 400** меняет θ всего на ~2·10⁻⁵ - пренебрежимо.

## Быстрая проверка

```bash
.venv/bin/python verify.py
```

Что проверяется:
1. решатель: точность при k₁ = k₂ и совпадение с аналитическим решением
2. данные: если папки `data/` нет, они генерируются (детерминированно, ~1 с)
3. ручной backprop против центральных разностей
4. сохранённые веса из `models/` дают ту же медиану ошибки k, что в отчёте
5. ошибка NLS на шумных данных согласуется с оценкой τ‖J⁺‖_F

Ожидаемый вывод заканчивается строкой `пройдено проверок: 7/7`

